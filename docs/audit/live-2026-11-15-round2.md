# Live production audit, round 2 (2026-11-15)

> Read-only audit of production at web/API `cf482f2`, before PR #12. Evidence paths refer to a scratch
> directory that was not committed; findings LA-01…LA-17 and their fixes are tracked in `TODO.md` (R2-*).


Scope: https://gridstorm.vercel.app with API https://gridstorm-api.onrender.com (`/health` git_sha `cf482f2`). This was read-only. Every non-GET API call was intercepted with `route.abort('blockedbyclient')`; the only pass-through was `POST /api/v1/scenarios/validate`. Blocked calls: 1× `POST /simulations` (guided Run), 4× `POST /comparisons` (Compare button and `auto=1` links). Nothing was written to production.

Scripts, raw JSON and screenshots are in `GridStorm/apps/web/.live-audit/`. Evidence paths below are relative to that folder. The directory is scratch and can be deleted.

**Production state changed during the audit (not a defect, but it affects reproduction).** At about 13:54Z, the SciGRID precomputed jobs `c800561d`, `5dafdc1a`, `f2fc0cf3` and `5323bc95` reported `result_available=false`, and `/result` returned 410. By about 14:20Z the same jobs reported `result_available=true`, and `/result` returned 200 with sha `e3e3494b…`, which matches `x-gridstorm-result-sha256`. `/health` git_sha did not change (`sims.json` vs `sims2.json`). The IEEE-14 jobs `25e3fb2a`, `4104c5fc`, `06b4f635`, `0137980b` and `2d47898b` still return 410.

**Comparison `ee5566d6-…` could not be opened.** `GET /api/v1/comparisons` returns **405** `method_not_allowed`: no list endpoint exists. The full id appears nowhere in the repo, and the UI has no comparison history. Compare was therefore audited on the stored comparison `4f5661ec-e6f1-4600-96ed-710709f10c36` (see LA-12).

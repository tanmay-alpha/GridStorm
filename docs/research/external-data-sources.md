# External data sources

Status: research notes (2026-11-14). Each row was checked on the official page(s) linked in the row on
2026-11-14. "Freely downloadable" (no fee) is **not** the same as "openly redistributable" (we may publish
copies or derivatives in the GitHub repo, deployed artifacts or API responses). GridStorm commits only data
whose redistribution is permitted and whose files are small (contract: `network.nc` ≤ 10 MB, artifacts
< 5 MB); everything else is fetched at build time by the user and described in a `dataset-manifest/1.0`
(`license.redistribution: permitted|restricted|unknown`).

Decision vocabulary: **use now** (needed for the current contract scope) · **candidate** (permitted, useful,
not yet in scope) · **reference only** (cite/compare, do not ingest or redistribute) · **defer** · **reject**.

## 2. Notes and caveats

- **Provenance labels.** Reanalysis (ERA5, MERRA-2 via NASA POWER) and forecasts (DemandCast) are `modeled`;
  TSO/EIA metered statistics are `observed`; SimBench grids are `synthetic`; capacities compiled by GEM from
  mixed sources are best labelled `estimated` unless GEM marks them as reported values.
- **ENTSO-E list verification.** The free-re-use list is a PDF; our item mapping comes from automated text
  extraction (`231018_List_of_Data_available_for_reuse.pdf`, retrieved 2026-11-14 from the legal-terms page).
  Before ingesting any ENTSO-E item, re-check that item number against the current list manually.
- **OPSD.** Useful as a curated mirror, but it does not change the licence of the primary data; OPSD itself
  warns that some published data "might be subject to copyright".
- **Keys and accounts** (ENTSO-E token, CDS token, EIA key) are user secrets: they belong in the user's
  environment at fetch time, never in the repository, `.env.example` defaults, artifacts or manifests.
- **CEA India** is the only source in this list whose terms require prior permission for reproduction.
- **DemandCast/ERA5 licence drift.** DemandCast's release README still names the "Licence to use Copernicus
  Products", which the CDS replaced with CC BY 4.0 on 2025-07-02; manifests should record the licence in force
  at retrieval time together with `retrieved_at`.
